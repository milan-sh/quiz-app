# 🎯 Awesome Quiz App  

**A fun, interactive quiz application to test your knowledge with timed questions!**  


---

## 🚀 Features  
- ⏱️ **10-second timer** per question  
- 📊 **Smart scoring**: +1 for correct, -1 for wrong answers  
- 📱 **Fully responsive** (works on mobile/tablet/desktop)  
- 🎨 **Clean modern UI** with progress tracking  
- ⚡ **Instant results** after submission  

---
